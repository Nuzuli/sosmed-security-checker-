# 🛡️ Sosmed Security Checker

Aplikasi sederhana dan mudah digunakan untuk mengecek kekuatan kata sandi serta memberikan rekomendasi keamanan akun media sosial. Cocok untuk edukasi keamanan digital bagi pemula.

## ✨ Fitur
- ✅ Cek kekuatan kata sandi dengan penilaian skor
- ✅ Memberikan saran perbaikan secara rinci
- ✅ Menampilkan tips keamanan akun media sosial
- ✅ Menu yang mudah digunakan
- ✅ Tidak membutuhkan library tambahan

## 🚀 Cara Menggunakan

### Persyaratan
- Python 3.6 atau lebih baru sudah terinstal di komputer Anda

### Langkah
1. Unduh atau kloning repositori ini
2. Buka terminal/command prompt di folder proyek
3. Jalankan perintah:
   ```bash
   python keamanan_sosmed.py
